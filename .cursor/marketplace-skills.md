# Marketplace Skills

These marketplace skills should be enabled in Cursor for Signal Lab work.

| Skill | Why it is connected |
|---|---|
| `next-best-practices` | Keeps App Router, server/client component boundaries, and Next.js scripts consistent. |
| `shadcn-ui` | Guides use of local shadcn-style primitives instead of ad hoc UI. |
| `tailwind-v4-shadcn` | Helps preserve Tailwind token and component-class consistency. |
| `nestjs-best-practices` | Reinforces modules, DTO validation, filters, Swagger, and provider boundaries. |
| `prisma-orm` | Covers schema, migrations, generated client, and Prisma query patterns. |
| `docker-expert` | Supports Compose debugging, health checks, volumes, and service networking. |
| `postgresql-table-design` | Helps review indexes, field types, and migration safety. |

Custom skills cover Signal Lab-specific behavior that marketplace skills do not know: exact metric names, scenario semantics, Loki labels, Sentry expectations, and the assignment-specific orchestrator workflow.
